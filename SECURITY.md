# Security Policy

ZEROLEAK is a portfolio application and is provided without a guarantee that it will detect or redact every sensitive value. Do not use it as the sole control for protecting production secrets or personal information.

## Reporting a vulnerability

**Before public release, replace this placeholder with a monitored private contact:** `[ADD SECURITY CONTACT EMAIL OR PRIVATE REPORTING URL]`.

Please do not include real credentials, private user data, or exploit payloads in a public issue. Until the contact above is configured, use GitHub's private vulnerability reporting for the repository if the repository owner has enabled it. Do not publish details until the maintainer has acknowledged the report and coordinated disclosure.

## Scope

Reports may cover data disclosure, unsafe rendering, dependency/build compromise, model-loading behavior, and browser-side denial of service. The application cannot protect against a compromised browser, device, extension, dependency, or deployment origin.
